# MEDI-PASS SAFE - Backend

> AI 디지털 약 여권 서비스 **MEDI-PASS SAFE**의 백엔드 레포지토리

---

## 📌 프로젝트 소개

사용자가 약 봉투를 촬영하면 해외 반입 가능 여부를 확인하고, 현지에서 증명·분실·대응까지 지원하는 서비스입니다.

---

## 🛠 기술 스택

- **Language**: Java
- **Framework**: Spring Boot
- **Build Tool**: Gradle
- **Database**: MySQL

---

## 🌿 브랜치 네이밍 규칙

- 브랜치 명: `(태그/#이슈번호)`
- 예시: `feat/#2`, `fix/#3`

---

## ✏️ 커밋 메시지 규칙

| 타입 | 설명 |
| --- | --- |
| `feat` | 새로운 기능 추가 또는 기존 기능 개선 |
| `fix` | 버그 수정 |
| `refactor` | 코드 리팩토링 (기능 변화 없이 구조 개선) |
| `docs` | 문서 작업 (README 등) |
| `test` | 테스트 코드 추가 또는 수정 |
| `chore` | 패키지 매니저 수정, 그 외 기타 수정 (예: .gitignore) |
| `comment` | 주석 수정, 추가 |
| `merge` | 브랜치 병합 |
| `rename` | 파일 또는 폴더명 수정 |
| `remove` | 파일 삭제 |
| `init` | 프로젝트 초기 세팅 |
